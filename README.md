# Xizmatlar katalogi

O‘zbek tilidagi davlat va kommunal xizmatlar katalogi. Ilova oddiy HTML, CSS va
JavaScript bilan ishlaydi; toifalar bo‘yicha filtrlash, xizmat qidirish va
xizmat ma’lumotlarini ko‘rish mumkin.

## Ishga tushirish

`index.html` faylini zamonaviy brauzerda oching. Alohida paket yoki server talab
qilinmaydi.

## Ma’lumotlarni to‘ldirish

Xizmat nomlari va toifalari `data.js` faylida saqlanadi. Rasmiy tashkilot,
manzil, xarita, ish vaqti, narx, kutish vaqti, havola, telefon, murojaat
tartibi, yangilanish sanasi va manbani tegishli idora ma’lumotlari bilan
tasdiqlab yangilang. Tasdiqlanmagan qiymatlar ilovada ataylab shunday
ko‘rsatiladi; ular rasmiy xizmat ma’lumotlari emas.

`app.js` katalog toifalari, xizmat kartalari, qidiruv va batafsil ma’lumot
oynasini boshqaradi.
